# Demo Script

## Blind Mode: Samia

1. Launch the app and select **Blind mode - Samia**.
2. Type `read arabic garden` or tap a book from the list.
3. On the reader screen, tap **Start reading**.
4. Tap **Next** to move pages and confirm reading progress continues.
5. Close and reopen the same book to show saved progress.

## Deaf Mode: SignBook

1. Launch the app and select **Deaf mode - SignBook**.
2. Pick an Arabic or Moroccan story from the visual grid.
3. Show the avatar placeholder and the page text panel.
4. Point out gloss chips: checked chips have a SiGML mapping, fallback chips stay visual.
5. Tap **Next** and show the haptic/visual page change.

## Explore Mode

1. Select **Explore**.
2. Open Samia, then return and open SignBook.
3. Explain that the same library content adapts into voice-first and visual-first reading paths.
